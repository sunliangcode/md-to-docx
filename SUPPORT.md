## Before opening an issue

1. Search [existing issues](https://github.com/sunliang11/md-to-docx/issues) for duplicates.
2. Reproduce with the latest `main` (or a release tag).
3. Include: OS, Python version, command line / API call, minimal Markdown sample, and expected vs actual output.

## Maintainer response

This is a volunteer-maintained open-source project. Maintainers triage issues as capacity allows; there is no guaranteed SLA. Security reports are prioritized per [SECURITY.md](SECURITY.md).

## Commercial / consulting

There is no official paid support channel. For self-hosted / agent workflows, prefer local install and the docs above.
